# Эмблемы реальных клубов

Файлы в этой папке содержат эмблемы состава Ла Лиги 2026/27. Их имена исторически совпадают с `team_id` этого турнира, но код приложения больше не строит путь к файлу из сезона и ID.

Единый контракт находится в `src/assets/data/teams.json`:

```json
{
  "key": "real-madrid",
  "ids": ["7004", "8379"],
  "name": "Реал Мадрид",
  "logo": "assets/logos/real-clubs/2026-27/8379.png"
}
```

- `key` — постоянный внутренний идентификатор клуба;
- `ids` — все известные ID клуба во внешнем API для разных сезонов и турниров;
- `logo` — единственный используемый приложением путь к эмблеме.

При добавлении нового сезона или Лиги чемпионов добавьте новый внешний ID в `ids` существующего клуба. Если клуба ещё нет в каталоге, создайте новую запись и положите эмблему в удобную подпапку: имя файла больше не является частью контракта.

# Эмблемы реальных клубов Ла Лиги 2026/27

Имя PNG-файла должно совпадать с `team_id` футболиста во внешнем API:

```text
8366.png
8367.png
...
8385.png
```

Для текущего состава нужны файлы с идентификаторами от `8366` до `8385` включительно. Рекомендуется прозрачный PNG с одинаковым квадратным холстом. После добавления файла достаточно обновить страницу — менять конфигурацию или код не требуется.

# Иконки трофеев Зала славы

Активные иконки подключены в PNG-формате:

- `la-liga-primera.png` — чемпион Примеры / общего зачёта Ла Лиги;
- `la-liga-segunda.png` — чемпион Сегунды;
- `cup.png` — Кубок Ла Лиги;
- `champions-league.png` — Лига чемпионов;
- `world-cup.png` — чемпионат мира;
- `club-world-cup.png` — клубный чемпионат мира;
- `euro.png` — чемпионат Европы.

SVG-файлы остаются безопасными заглушками. Пути активных иконок задаются в `TROPHY_ICONS` внутри `achievement.service.ts`. Рекомендуемый размер исходника — не меньше 96×96 px.

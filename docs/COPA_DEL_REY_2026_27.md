# Кубок Короля 2026/27 — заготовка жеребьёвки

Рейтинговый срез зафиксирован 22 октября 2026 года после 9-го тура Ла Лиги. Порядок таблицы: очки, разница ФО, набранные ФО. Машиночитаемая копия среза находится в `config.cup.draw` сезона `2026-27/spain.json`.

## Формат

- 48 команд, double elimination по схеме сезона 2025/26.
- Отбор: 16 матчей между командами с мест 17–48, база — 10-й тур Ла Лиги.
- В 1/16 верхней сетки 16 сеяных встречаются с победителями 16 матчей отбора, база — 12-й тур.
- Проигравшие отбора попадают в 1/16 нижней сетки и играют там с проигравшими верхней 1/16, база — 14-й тур.
- Дальнейшие стадии проходят в турах 16, 18, 20, 22, 24, 26, 28, 32 и 36. Переходы полностью повторяют прошлогоднюю схему и строятся автоматически.
- Как и в прошлом сезоне, гранд-финал состоит из одного матча без дополнительного reset-финала.

Административный проход Мартина вместо Орешина в нижней сетке 2025/26 не является частью схемы: Орешин был исключён из лиги, поэтому этот единичный результат не используется как правило перехода.

## Ничья по ФО

Критерии применяются строго по порядку:

1. ФО эффективного капитана с капитанским множителем; если капитан не сыграл, берётся вице-капитан.
2. Максимальные ФО сыгравшего игрока стартового состава, который не назначен капитаном или вице-капитаном.
3. Количество сыгравших игроков первоначального стартового состава.
4. Сумма ФО всех запасных без капитанского множителя, включая вышедших по автозамене.
5. При полном равенстве — переигровка в следующем туре Ла Лиги с тем же порядком критериев.

Для переигровки в карточке матча используются состав и статистика следующего тура; переход по сетке остаётся заблокированным, пока победитель не определён.

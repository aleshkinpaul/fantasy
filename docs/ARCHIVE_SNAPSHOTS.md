# Архивные снэпшоты турниров

Завершённые турниры не должны обращаться к `fantasy-h2h.ru` и не должны заново рассчитывать таблицы, матчи и призы в браузере. Для них используется неизменяемый локальный снэпшот.

## Структура

Снэпшот хранится в `src/assets/data/history/<datasetId>/`:

- `manifest.json` — версия схемы, связанные турниры, исходные API URL, дата создания, контрольные суммы и ожидаемые размеры;
- `view.json` — готовая рассчитанная модель страницы без циклических ссылок;
- `raw/` — замороженные исходные ответы API для аудита и восстановления.

API URL остаются в конфигурации сезона. Для архивного турнира они являются только сведениями о происхождении данных: production-клиент не использует их как автоматический fallback.

## Перевод актуального сезона в архив

1. Убедиться, что опубликованы финальные результаты всех туров, плей-офф и спонсорских призов.
2. Добавить сезон в список генератора или вызвать соответствующий генератор с его `datasetId`.
3. Получить ответы API один раз и сформировать `view.json`, `raw/` и `manifest.json`.
4. Сравнить рассчитанные матчи, таблицы, кубок, призы и профили с регрессионными эталонами.
5. Добавить в конфигурацию сезона:

```json
"dataSource": {
  "lifecycle": "archived",
  "snapshot": {
    "manifestUrl": "/assets/data/history/<datasetId>/manifest.json",
    "viewUrl": "/assets/data/history/<datasetId>/view.json",
    "schemaVersion": 1
  }
}
```

6. Выполнить `npm run archive:check`, тесты и production-сборку.
7. Открыть турнир, профиль участника и рейтинг с заблокированным доменом `fantasy-h2h.ru`.
8. Только после успешной проверки сменить статус турнира в `tournaments.json` на `completed`.

Для зафиксированных сезонов 2025/26 используется команда:

```bash
npm run archive:season-2025
```

Она воспроизводит проверенные ответы из `src/testing/season-2025-26` и поэтому не зависит от доступности внешнего API.

Legacy-снэпшоты 2024/25 при необходимости восстанавливаются командой:

```bash
npm run archive:legacy-2024
```

Эта команда обращается к сохранённым API-источникам и должна запускаться только вручную. После восстановления нужно проверить изменения и заново выполнить `npm run archive:check`.

## Ошибки и восстановление

Если `view.json` отсутствует, повреждён или имеет другую версию схемы, архивная страница должна показать ошибку загрузки. Автоматически обращаться к API запрещено: это могло бы незаметно изменить исторические итоги.

Перезапись существующего снэпшота допустима только после подтверждённого исправления исходных данных. Предыдущую версию следует сохранить в Git, а причину замены указать в коммите.

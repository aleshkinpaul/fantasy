## Реализация на сайте

Турнир доступен по адресу `/spain-cup?year=2024`. Сетка хранится локально в `src/assets/data/archive-cups.json` и не зависит от внешнего API при открытии страницы. Результаты воспроизводятся из сохраненного snapshot Ла Лиги 2024/25 командой:

```powershell
npm.cmd run import:archive-cup
```

Импорт проверяет наличие каждой команды и результата нужного тура. Для полуфиналов складываются результаты 30-го и 32-го туров. Итоговый пьедестал: `ducks`, `Andar con rodeos`, `BIG TURTLES` и `Lion Force`; оба проигравших полуфиналиста получают бронзу в Зале славы.

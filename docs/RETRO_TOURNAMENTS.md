# Ретро-турниры из CSV

Три турнира сезона 2023–24 работают без внешнего API и открываются со страницы турниров:

- Ла Лига 2023/24 — 28 участников, 38 туров;
- Лига чемпионов 2023/24 — 12 участников, 9 туров;
- Евро 2024 — 33 участника, 7 туров.

Итоговый snapshot хранится в `src/assets/data/retro-tournaments.json`. В нём сохранены место, суммарные ФО, показатели по турам, старое название команды и ссылка на известный профиль. Страница `/retro/:tournamentId` читает только этот файл.

## Повторный импорт

Исходные CSV не копируются в приложение. По умолчанию скрипт ищет три файла на один уровень выше корня проекта с исходными именами:

```powershell
npm.cmd run import:retro
```

При необходимости пути можно передать явно в порядке: Ла Лига, Лига чемпионов, Евро.

```powershell
node scripts/import-retro-tournaments.mjs "la-liga.csv" "ucl.csv" "euro.csv"
```

Сопоставление выполняется по нормализованному имени с учетом перестановки имени и фамилии. Опечатка `Кирил Яковченко` задана как явный alias. Стабильный `participantId` берётся из `achievements.json`; логотип — из наиболее старого доступного профиля после ретро-сезона: сначала из сезона 2024–25, а при его отсутствии — из первого более позднего сезона.

Участники без найденного профиля получают стабильный `retro-*` id, дефолтный логотип и метку «ретро-профиль». После ручного подтверждения связи её нужно добавить в реестр достижений или alias импорта и повторно запустить скрипт.

## Зал славы и трофеи

Первые три места каждого ретро-турнира внесены в `achievements.json`. Евро имеет отдельный тип титула `euro`.

Имена файлов для иконок трофеев описаны в `src/assets/icons/trophies/README.md`. В репозитории лежат безопасные SVG-заглушки; пользовательские изображения можно подложить поверх них без изменения шаблона Зала славы.

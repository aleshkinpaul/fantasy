# Обзор проекта FR Fantasy

## Назначение

FR Fantasy — одностраничный сайт для отображения авторских соревнований по фэнтези-футболу. Участники создают команды во внешней фэнтези-системе, а этот проект накладывает поверх их результатов собственный формат:

- H2H-матчи между профилями;
- этапы Apertura и Clausura, конференции и дивизионы;
- общий и кубковый зачет;
- таблицы по очкам и по фэнтези-очкам (далее — FO);
- статистика побед, ничьих, поражений, серий и разницы FO;
- медали за места в отдельных турах;
- авторские призовые номинации;
- отдельный командный формат Клубного чемпионата мира 2025.

Репозиторий содержит только frontend. Источниками истины одновременно являются:

1. локальные файлы участников и регламентов в `src/assets/data`;
2. внешний REST API `https://fantasy-h2h.ru/api/` с фактическими составами и очками;
3. расчетная логика Angular-компонентов и сервисов.

Готовые H2H-таблицы сервер не отдает: они строятся в браузере из календаря сезонного файла и туровых очков API.

## Текущие соревнования

| Сезон | Турнир | Страница | Реализация |
|---|---|---|---|
| 2025–26 | Ла Лига | `/spain/new?year=2025` | универсальная H2H-страница |
| 2025–26 | Лига чемпионов | `/champions-league/new?year=2025` | универсальная H2H-страница, два внешних этапа |
| 2025–26 | Чемпионат мира 2026 | `/world-cup/new?year=2025` | универсальная H2H-страница с отдельными правилами замен и призов |
| 2024–25 | Ла Лига | `/spain?year=2024` | архивная страница рейтинга |
| 2024–25 | Лига чемпионов | `/champions-league?year=2024` | архивная страница рейтинга |
| 2025 | Клубный чемпионат мира | `/club-world-cup?year=2024` | отдельная командная реализация |
| — | Кубок Испании | `/spain-cup` | заготовка без функционального содержимого |

`new` в URL означает новую H2H-реализацию, а не новый сезон. Это историческое имя маршрута.

## Формат сезона 2025–26 в данных

На 26 августа 2026 года в `assets/data/seasons/2025-26/` описано:

| Турнир | Участников в регламенте | Туров календаря | H2H-матчей | Этапы | Призы |
|---|---:|---:|---:|---|---:|
| Ла Лига | 49 | 38 | 912 | Apertura 1–15, Clausura 16–38 | 21 |
| Лига чемпионов | 48 | 17 | 253 | общий этап 1–8 + cup/play-off | 4 |
| Чемпионат мира | 32 | 8 | 80 | общий этап 1–3 + play-off | 9 |

В сезонных файлах участников больше, чем в отдельных регламентах: по 52 профиля доступны для Ла Лиги и Лиги чемпионов, но в конфигурации турниров участвуют соответственно 49 и 48. Нельзя считать весь массив `profiles` составом конкретной лиги — для этого используется `config.profiles`.

## Владение данными

| Что меняется | Где менять |
|---|---|
| Имя, ник, ссылка и логотип участника актуального турнира | `profiles` в `src/assets/data/seasons/{сезон}/{турнир}.json` |
| Участники турнира, календарь и этапы | `config` в том же сезонном файле |
| Кубковая сетка | `config.cup` сезонного файла |
| Призовые карточки | `config.prizes` сезонного файла |
| Формула определения номинантов | `competition/domain/prize-calculator.ts` |
| Реальные очки и составы | внешний API, локально не редактируются |
| Названия реальных клубов для архивной статистики | `src/assets/data/teams.json` |
| Команды и сетка КЧМ-2025 | `teams`, `groups`, `tours` записи `club-world-cup` |
| Турниры, сезоны, статусы и ссылки главной страницы | `src/assets/data/tournaments.json` |

## План развития

Согласованный порядок и подробный план следующих продуктовых функций зафиксирован в [FEATURE_ROADMAP.md](FEATURE_ROADMAP.md).

## Термины

- **Профиль** — участник сообщества; его `id` совпадает с ключом пользователя во внешнем API.
- **Фэнтези-команда / squad** — команда участника во внешней системе; имеет отдельный `team.id`.
- **FO** — фэнтези-очки участника в туре (`tour_score`).
- **H2H-очки** — 3 за победу, 1 за ничью, 0 за поражение.
- **drawGap** — максимальная включительно разница FO, при которой матч считается ничьей.
- **Apertura / Clausura** — первая и вторая части сезона Ла Лиги.
- **Common** — агрегированный результат нескольких этапов.
